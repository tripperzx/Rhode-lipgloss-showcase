## About

A single-page interactive multimedia showcase built for a Multimedia Systems and Applications
assignment. The project combines text, graphics, animation, audio, video, and interactivity into
one cohesive product page, using Rhode Lip Gloss as a case study.

This is an academic simulation only — not an official product of Rhode or its parent company.

## Multimedia components used

| Component | Where it appears |
|---|---|
| Text | Product story copy, shade descriptions |
| Graphics | CSS-drawn gloss tube icon, gradient "swatch" circles, animated blobs |
| Animation | Hero title reveal, floating tube, scroll-reveal story sections, shine button |
| Audio | Ambient background sound toggle (add your own file) |
| Video | Embedded product demo clip (add your own file) |
| Interactivity | Clickable shade swatches, audio toggle, animated CTA button |

## Project structure

```
index.html
style.css
script.js
assets/
  images/   -> poster-placeholder.svg (replace/add your own images)
  video/    -> add demo.mp4 here
  audio/    -> add ambient.mp3 here
```

## Adding your own media

1. Drop a short demo/swatch video into `assets/video/demo.mp4`.
2. Drop a royalty-free ambient audio clip into `assets/audio/ambient.mp3`.
3. Optionally replace `assets/images/poster-placeholder.svg` with a real photo/poster frame.

## Running locally

Just open `index.html` in a browser — no build step or server required.

## Deploying with GitHub Pages

1. Push this project to a public GitHub repository.
2. Go to **Settings → Pages → Source: main branch (root)** → Save.
3. Your live site will be available at:
   `https://<your-username>.github.io/<repo-name>/`
